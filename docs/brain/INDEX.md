## 🏗️ Visão Geral da Arquitetura
- **Framework:** Next.js 16 + React 19 + Turbopack + Tailwind CSS v4.
- **Node.js Target:** 24.x LTS (compatível com runtime Vercel).
- **Provedor de Agendamento:** Buffer API v1 (canais ativos: LinkedIn HBCompany, Instagram HBCompany Lab, Instagram Pessoal).
- **Formatos de Mídia Suportados:**
  - Vídeos Motion 9:16 em HTML5 Canvas/GSAP e MP4 otimizado.
  - Mockups 3D de alta fidelidade para Desktop e Mobile.
  - Carrosséis Bento Multi-Slide gerados em HTML/SVG e exportáveis em PDF para LinkedIn e Instagram.
